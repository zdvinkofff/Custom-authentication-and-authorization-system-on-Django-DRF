# Custom Authentication & Authorization System

Модуль кастомной аутентификации и авторизации пользователей для веб-приложений, разработанный на Django REST Framework.

## 🛠 Технологический стек:
- Python, Django, DRF
- Сезоны/Токены: Simple JWT (создание и обновление access/refresh токенов)

## 🚀 Ключевые фичи:
- Система регистрации и логина пользователей с хэшированием паролей.
- Ролевая модель доступа (RBAC): разграничение прав для обычных пользователей и администраторов.
- Асинхронное обновление токенов для обеспечения непрерывной и безопасной сессии.


Система успешно различает:

* неавторизованного пользователя (401);
* пользователя без доступа (403).
